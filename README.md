

* このリポジトリには、ブラウン大学で開講されている学部生向けの計量経済学コース（Econ 1630, Mathematical Econometrics I）の講義スライドが含まれています。
* このコース資料は、Jonathan Roth氏とPeter Hull氏が共同で作成したものです。
* 本レポジトリは、元の英語版スライドに加えて、英語版スライドを日本語に翻訳したものを提供しています。
  * 統計学・計量経済学の用語の日英対照表は[こちら](terms.md)。
  * 間違いの指摘や改善の提案は、Issueを通じてお知らせください。
